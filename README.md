# Editor de vídeo web com IA

Editor de vídeo profissional no navegador (React + TypeScript + Node.js), inspirado na variedade de recursos de editores como o CapCut Pro. Projeto independente: sem código proprietário e sem desbloqueio de recursos pagos.

Status: fase 1 (auditoria) concluída. Veja `docs/auditoria/`.
